# ClinicalAuditDB-Medication-Safety

## Project Overview
This repository contains a professional SQL portfolio focused on **Medication Safety** and **Clinical Data Analytics**. As a Health IT Specialist, I developed these queries to perform clinical audits, track medication errors, and analyze patient outcomes. The primary goal of this project is to demonstrate technical SQL proficiency within the healthcare domain.

## Key Focus Areas
- **Clinical Audits:** Identifying medication administration discrepancies.
- **Patient Safety:** Reducing adverse drug events through data-driven analysis.
- **Digital Health:** Bridging the gap between raw health data and clinical decision-making.

## SQL Competencies Demonstrated
- **Basic:** Joins, Aggregations, Filtering.
- **Intermediate:** Common Table Expressions (CTEs), CASE WHEN statements, HAVING clauses.
- **Advanced:** Window Functions (ROW_NUMBER, RANK, LAG) for longitudinal data analysis.

## Project Structure
- `schema.sql`: Database schema definition (Tables: Patients, Medications, AuditLogs).
- `seed_data.sql`: Synthetic data for testing and analysis.
- `queries/`: SQL scripts categorized by complexity level (Basic, Intermediate, Advanced).
